# Solo Leveling Life OS

Минималистичное React-приложение для MVP личной RPG-системы: XP, 5 веток, недельный босс, кристаллы, награды и штрафы.

## Как запустить локально

```bash
npm install
npm run dev
```

## Как собрать

```bash
npm run build
```

## GitHub Pages

Проект настроен под репозиторий `solo-life-os`.

В `vite.config.js` указано:

```js
base: '/solo-life-os/'
```

Если репозиторий будет называться иначе, поменяй `base` на `'/название-репозитория/'`.

## Сохранение данных

Данные хранятся в браузере через `localStorage`.

Для безопасности используй кнопки:

- `Экспорт` — скачать JSON-бэкап.
- `Импорт` — восстановить прогресс из JSON.

Пока нет автоматической синхронизации между телефоном и компьютером.
